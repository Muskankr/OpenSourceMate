# Developer Tutorials

Welcome to the OpenSourceMate developer tutorials. These guides provide practical, step-by-step instructions for common contribution tasks.

Each tutorial references the repository's existing structure and conventions.

[Read the tutorial](./add-a-new-page.md)

### 2. Add a Backend Endpoint

[Read the tutorial](./add-a-backend-endpoint.md)

### 3. Add a Skill Mapping

Learn how to extend the skill mapping configuration, organize technologies into groups, and test language-to-group resolution.

[Read the tutorial](./add-a-skill-mapping.md)

### 4. Add a Frontend Component with a Test

Learn how to create reusable React components using TypeScript and test them with Jest and React Testing Library.

[Read the tutorial](./add-a-component-with-a-test.md)

## Before Contributing

- Read the relevant tutorial before making changes.
- Follow the existing project structure and coding conventions.
- Add or update tests for your changes.
- Run the relevant checks before opening a pull request.
- Keep contributions focused and avoid unrelated modifications.

If you find an issue with a tutorial, consider contributing an improvement through a pull request.
