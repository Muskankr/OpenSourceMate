# Architecture Decision Records

This folder records significant architecture decisions and their trade-offs.

Use the [ADR template](template.md) for new records. Keep each record concise and
include its context, decision, and consequences. Accepted decisions describe the
current direction; add a new ADR to document a later change rather than silently
rewriting an earlier decision.
