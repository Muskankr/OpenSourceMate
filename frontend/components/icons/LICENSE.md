- **License**: [MIT License / ISC License](https://opensource.org/licenses/MIT)
- **Usage**: Used for database (SQL) and the neutral code bracket fallback icon (`< / >`).

## Content Security Policy (CSP) Invariant

All icons are strictly embedded directly as inline React SVG elements with `aria-hidden="true"` and local theme styling. No SVG files, fonts, or assets are fetched from external hosts or third-party CDNs, ensuring that the application's strict Content Security Policy remains intact.
